# Vexa

Канал установщиков и подписанных обновлений браузера Vexa для Windows x64.

[Скачать Vexa 1.0.1](https://github.com/nelmex007/Vexa/releases/tag/v1.0.1). Для первого запуска закрой старую Vexa и используй `Vexa_1.0.1_x64-setup.exe`. Переносимый EXE доступен отдельно.

В 1.0.1 исправлен индикатор загрузки после переходов и остановки страницы. Окна, открываемые сайтами, становятся вкладками внутри браузера с сохранением opener/postMessage, POST-форм и приватности.

Автозапуск: Настройки → Общие → Запуск браузера → «Запускать Vexa при входе в систему». Откроется основной профиль с ленивым восстановлением вкладок.

Из установленной Vexa 1.0.0: Настройки → Обновления → Проверить и установить.

[Все выпуски](https://github.com/nelmex007/Vexa/releases). Автообновление использует `releases/latest/download/latest.json`; проверяются подпись пакета и подписанный номер версии. Приватный ключ подписи в репозитории не хранится. Подпись Tauri не заменяет Windows Authenticode-сертификат издателя.

Требуется Microsoft WebView2 Evergreen Runtime. Реальная регистрация Gmail не выполнялась; проверены локальные сценарии авторизации. VPN требует действующего сервера и конфигурации.
