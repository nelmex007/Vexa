# Vexa

Канал установщиков и подписанных обновлений браузера Vexa для Windows x64.

[Скачать Vexa 1.0.0](https://github.com/nelmex007/Vexa/releases/tag/v1.0.0). Для первого запуска закрой старую Vexa и используй установщик `Vexa_1.0.0_x64-setup.exe`. Переносимый EXE доступен отдельно.

В 1.0.0: оформление с предпросмотром и отменой, настраиваемая новая вкладка и панель, отдельные профили, два сайта рядом, разрешения сайтов, исправление завершения скачиваний и кнопка папки загрузок.

[Все выпуски](https://github.com/nelmex007/Vexa/releases). Автообновление использует `releases/latest/download/latest.json`; откат становится доступен после первого обновления из приложения. Подпись Tauri не заменяет Windows Authenticode-сертификат издателя.

Обновление проверяет подпись пакета и подписанный номер версии. Файлы `latest.json` и `.sig` поставляются вместе с установщиком. Приватный ключ подписи в этом репозитории не хранится.

Для работы требуется Microsoft WebView2 Evergreen Runtime. VPN требует собственного действующего сервера и конфигурации.
