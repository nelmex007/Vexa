# Vexa

Канал установщиков и подписанных обновлений браузера Vexa для Windows x64.

[Скачать Vexa 1.0.2](https://github.com/nelmex007/Vexa/releases/tag/v1.0.2). Закрой старую Vexa и используй `Vexa_1.0.2_x64-setup.exe`. Переносимый EXE доступен отдельно. Настройки и вкладки существующего профиля сохраняются.

В 1.0.2 вкладки больше не теряются за краем окна: стрелки, колёсико мыши и список всех вкладок с поиском. Активная вкладка остаётся видимой после изменения размера окна; новая вкладка и кнопки управления окном всегда доступны.

Кнопка аккаунта открывает панель Google. Desktop OAuth подготовлен, но Google-вход в этом выпуске отключён до настройки проекта разработчиком. Облачной синхронизации пока нет. Локальные профили сохранены и доступны отдельно — они разделяют cookies, историю и оформление на этом компьютере без регистрации.

В 1.0.1 исправлены зависающие индикаторы загрузки, окна сайтов открываются вкладками с сохранением opener/postMessage, POST-форм и приватности. Автозапуск находится в Настройки → Общие → Запуск браузера.

Из установленной Vexa: Настройки → Обновления → Проверить и установить.

[Все выпуски](https://github.com/nelmex007/Vexa/releases). Автообновление использует `releases/latest/download/latest.json`; проверяются подпись пакета и подписанный номер версии. Приватный ключ подписи в репозитории не хранится. Подпись Tauri не заменяет Windows Authenticode-сертификат издателя.

Требуется Microsoft WebView2 Evergreen Runtime. VPN требует действующего сервера и конфигурации.
