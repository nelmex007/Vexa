# Vexa

Канал установщиков и обновлений Vexa для Windows x64.

[Скачать установщик Vexa 1.1.2](https://github.com/nelmex007/Vexa/releases/download/v1.1.2/Vexa_1.1.2_x64-setup.exe). Перед ручной установкой закрой Vexa. Основные история, закладки, настройки и вкладки сохраняются. В 1.1.1 и новее можно использовать Настройки → Обновления.

В 1.1.2 исправлены зависшие строки загрузок после повторных попыток: новая COM-операция WebView2 привязывается к исходному переходу, старые обработчики освобождаются. Список и toolbar сверяются с настоящим состоянием движка; поздний прогресс не возвращает готовую загрузку в активные. Пауза, продолжение, открытие папки и удаление записи без удаления файла сохранены.

Автозапуск исправляет существующую включённую запись Windows после замены переносимого EXE. Отключение через Windows сохраняется. Встроенная привязка Google полностью удалена из UI и backend-команд; создавать Google Cloud проект и импортировать OAuth JSON больше не нужно. Прежние файлы привязки удаляются из текущего основного профиля. Cookies и входы на сайтах сохраняются; облачной синхронизации нет.

Вкладки сжимаются и переносятся в компактные строки без стрелок. Закреп сохраняется в сессии и не мешает выгрузке из памяти. Редактор новой вкладки поддерживает 2–4 цвета градиента, линейный/радиальный вид, угол и насыщенность. Блокировщик использует семь списков, сетевую фильтрацию, косметические правила, скриптлеты и ресурсы-подмены. Универсальная недетектируемость и отсутствие рекламы на всех видеосервисах не гарантируются.

Проверки 1.1.2: 33 Rust-теста, 8 тестов оформления/миграций, 78 проверок в настоящем WebView2. Проверены потеря событий загрузки, два обрыва с последующим успешным скачиванием, пустые файлы, неизвестный размер, pause/resume, инкогнито, popup/POST и автозапуск в изолированной ветке реестра. Production NSIS собран без тестовой feature; подпись updater проверена на установщике.

Windows Authenticode-подписи издателя у выпуска пока нет. Smart App Control может блокировать запуск из-за неподтверждённого издателя. Подпись Tauri проверяет пакет обновления и номер версии, но не заменяет Windows-подпись. Переименование EXE этого ограничения не решает. [Объяснение Microsoft](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

[Все выпуски](https://github.com/nelmex007/Vexa/releases). Канал updater: `releases/latest/download/latest.json`. Требуется WebView2 Evergreen Runtime. VPN требует действующего сервера и конфигурации.

Переносимый EXE доступен отдельно; лицензии и соответствующие исходники скриптлетов находятся в `Vexa-1.1.2-third-party-notices.zip` и включены в установщик. Репозиторий служит каналом выпусков.
