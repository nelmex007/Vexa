# Vexa

Канал установщиков и подписанных обновлений Vexa для Windows x64.

[Скачать установщик Vexa 1.1.1](https://github.com/nelmex007/Vexa/releases/download/v1.1.1/Vexa_1.1.1_x64-setup.exe). Закрой браузер и запусти установщик. Основные настройки, история, закладки и вкладки сохраняются. Для старой переносимой 1.0.2 этот шаг нужно выполнить один раз вручную: ограничение её кнопки обновления находится в уже собранном коде.

В 1.1.1 переносимая и установленная копии скачивают проверенный пакет прямо из Настройки → Обновления. Отдельный переключатель включает автоскачивание после обнаружения новой версии; по умолчанию он выключен. Проверка при запуске происходит не чаще раза в сутки. Скачанный пакет сохраняется, проверяется по подписи и повторно используется. Установка начинается только по кнопке. В переносимой копии откроется обычный установщик текущего пользователя.

Вкладки сжимаются по ширине окна; при большом количестве переносятся в компактные строки без стрелок. Закреплённые вкладки стоят первыми значками, сохраняются в сессии и переключаются через Ctrl+Shift+P или меню. Закреп не запрещает выгрузку страницы из памяти.

Редактор новой вкладки позволяет выбрать 2–4 цвета градиента, линейный или радиальный вид, угол и насыщенность с живым превью. Локальные профили убраны из интерфейса и отключены в обычной сборке.

Блокировщик использует семь списков, нативную сетевую фильтрацию, косметические правила, скриптлеты и ресурсы-подмены. Unbreak и Quick fixes улучшают совместимость с anti-adblock; универсальная недетектируемость и отсутствие рекламы на всех видеосервисах не гарантируются. Списки обновляются в фоне; защиту сайта можно переключить возле адреса.

Google Desktop OAuth подключается импортом JSON без пересборки; на Windows конфигурация защищена DPAPI текущего пользователя. Проект Google Cloud владельца приложения ещё не создан, поэтому без импортированной конфигурации вход недоступен. Облачной синхронизации пока нет.

Проверки 1.1.1: 39 Rust-тестов, 7 тестов тем, 10 проверок скачивания и 28 проверок настроек/permissions/updater в настоящем WebView2. Production NSIS собран без тестовой feature; проверены подпись установщика и подписанный номер версии. Полная проверка функций 1.1.0 ранее включала 148 native проверок.

[Все выпуски](https://github.com/nelmex007/Vexa/releases). Updater использует `releases/latest/download/latest.json`, проверяет подпись пакета и подписанный номер версии. Подпись Tauri не заменяет Windows Authenticode-сертификат издателя. Требуется WebView2 Evergreen Runtime; VPN требует действующего сервера и конфигурации.

Переносимый EXE доступен отдельно; соответствующие лицензии и исходники скриптлетов находятся в `Vexa-1.1.1-third-party-notices.zip` и включены в установщик. Этот репозиторий служит каналом выпусков.
